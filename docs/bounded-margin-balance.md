# Basic 的可选单日融资余额

在原主目录使用现有入口，显式提供交易日：

```powershell
pwsh -NoProfile -File .\scripts\Start-MainlandAnalysis.ps1 -UseProjectEnv -Ticker 600919.SH -AnalysisDate 2026-11-13 -BankSnapshot '<有效的 UUID:SHA256>' -MarginDate 2026-11-13
```

示例中的身份引用必须替换为原流程得到且仍有效的引用。可加 `-CheckOnly` 检查参数和源码绑定；它不会读取 Token、验证真实数据或启动分析。实际分析仍须精确输入 `START`。不提供 `-MarginDate` 就不启用本项，不会隐含启用 `-Moneyflow`、旧 `flow_sentiment`、公告、政策、热榜或 `all`。

## 实际范围

只向 Tushare 的 `https://api.waditu.com/dataapi/margin_detail` 查询一个已验证的沪深人民币股票、一个明确指定的交易日，固定字段 `trade_date,ts_code,rzye`。支持现有 `.SH`/`.SS` 同证券别名和 `.SZ`；不支持北交所、基金或指数。`rzye` 是融资余额，单位人民币元；不以融券余额 `rqye` 或融券余量 `rqyl` 替代，不静默换算。

指定日须不晚于分析截止日，并与本次已验证市场快照的有效交易日一致。发送前核对权威证券身份、快照 manifest/内容摘要、可用来源记录及本次运行持有的实际快照；不会根据工作日、价格最后一行或“最新”自行选另一天。不匹配时不读取该项凭据、不发请求，报告缺少绑定。日期下限 2010-01-01 是当前本地准入范围，不代表官方承诺历史完整。

每会话最多一次该接口 POST，复用现有共享 Tushare 请求协调器和每分钟 40 次本地安全上限，计入原数据＋模型共 60 次/1200 秒协作式预算。与资金流同时启用时各最多一次，均计入同一个总预算。失败发送也计数；无自动分页、重试、重定向、备用接口或日期回退。关闭/清理不覆盖首错，预算或取消停止不会变成可继续的普通缺失。同步 HTTPS 传输复用最多 30 秒/会话剩余时间、64 KiB 边界；不创建后台采集线程，但不能强行取消操作系统内部 DNS 阻塞。

Token 仅由既有安全机制在内存使用，不进入命令行、日志或新文件。身份和三张财报客户端的准入未扩展。失败诊断复用受审闭合传输诊断契约，不保存响应正文、任意字段名/值或异常消息。合法数据只保留规范化数值、日期、收到时间、来源和摘要；摘要不是原始字节回放证明。

## 数据与报告边界

字段按返回 `fields` 名称映射，只投影 `trade_date,ts_code,rzye`；额外包络/data字段、额外列丢弃，可选元数据缺失不阻塞。核心列缺失、所有重复列、行列长度不一致、错股、错日期、多行/重复行、负值和非有限值仍不可用，其他独立分析继续，预算/取消等安全停止不吞掉。共享 UTF-8、64 KiB、16层、4096节点（含键）、64列限制和 JSON 重复键拒绝适用于全部内容。合法零与空表/缺失不同。本地金额最多六位小数、上限 `1e14` 元，并非官方精度保证。空表不证明零余额、没有杠杆、清偿、停牌或不具资格。

观察 v2 / 诊断 v3 仅保存 `projected_data_sha256`（固定接口/核心字段/绑定/校验行）和规范化观察摘要，不对被丢弃内容哈希或留存。旧 v1/诊断 v2 的 `raw_response_sha256` 保留旧含义，只读兼容；不改旧收据，不混用字段。未知控制元数据不视作官方完整性证明，不启用分页，只报告实际合格单日记录。

规范化数字进入情绪分析员的独立融资余额辅助段落，并单列于 `1_analysts/margin_balance.md` 和 `complete_report.md`。单日余额不是净流入、持仓变化、新闻或舆情，更不是趋势；它不新增决策 Source Fact、策略断言或改变最终评级规则。默认 Basic、历史报告及评级保持原有行为。

所有获取结果标记 `retrospective_backfill`。交易日期小于截止日期不能证明当时已发布；接口缺少逐条发布时间和历史修订保证，不能用于严格时点回测。

## 依据与验证状态

[官方明细契约](https://tushare.pro/document/2?doc_id=59)给出最低 2000 积分、单次最多 6000 行及 `rzye` 元单位；本功能只允许一股一日最多一行。[积分规则](https://tushare.pro/document/1?doc_id=290)是账户准入/频率规则，不是逐次扣积分。下述真实查询已成功，但不保证未来账号准入，不会购买或开通服务。

明细文档称次日约 08:30 更新，[更新表](https://tushare.pro/document/1?doc_id=108)称每日 09:00，部分周五记录下周一上午更新；不能据此保证任意行的发布时间。[上交所说明](https://www.sse.com.cn/market/othersdata/margin/detail/index.shtml)区分当前标的明细与含调出标的的汇总，不能从空表推导余额为零。官方沪深/北交所文字覆盖不一致，本入口只承诺代码支持沪深。

除合成数据、假传输、真实本地协调器、分析员/图消息路径和内存报告的离线验证外，600919.SH / 2026-11-13 的融资余额已通过独立真实查询。2026-11-14 的增强会话 `9bdebf8455c147d4a357b1e9ef4b65cc` 又在同次运行取得一条融资余额记录，并由情绪分析员正确引用；该会话在后续基本面模型传输阶段失败，没有最终完整报告。最近增强会话 `af30773832b646e08a2e2a9992813485` 在市场证据门禁停止，未到达融资采集，后续修复尚未真实复跑。不能把这些局部成功称作增强版完整流程或其最终 Windows 报告导出已验收，也不能解释旧的未留存响应。详见[主入口与验证状态](bounded-mainland-entry.md)。

## Basic 深度与两个显式增强

在项目主目录运行以下命令，替换仍有效的身份引用：

```powershell
pwsh -NoProfile -File .\scripts\Start-MainlandAnalysis.ps1 -UseProjectEnv -Ticker 600919.SH -AnalysisDate 2026-11-13 -BankSnapshot '<有效的 UUID:SHA256>' -Moneyflow -MarginDate 2026-11-13
```

入口保持中文 Basic 深度、四分析员、研究与风险讨论各一轮；并非 `all` 模式。两个选项均已接到正式配置与同一运行作用域，使用现有共享预算；省略哪个就不启用哪个。可先加 `-CheckOnly` 做无凭据/无数据调用的参数和源码绑定检查，实际运行仍需精确 `START`。未提交代码本身不妨碍在当前主目录运行，但有效身份、依赖、数据/模型准入及运行时安全检查仍必须满足。

只有交易日期不能证明当时已经发布。尤其深市周五记录通常要到下周一上午更新；截至周五的历史查询仍标记事后回补，不视作周五当时已知。此组合不启用热榜、公告自动采集、政策或其他未接入的 `flow_sentiment` 项，不改变评分。
