# 有界单股票入口

本文件随候选安装后生效。候选目录不是已激活的运行包；不要运行旧 prepared 包。

安装并核验后，在普通账户 PowerShell 运行：

```powershell
pwsh -NoProfile -File './scripts/Start-MainlandAnalysis.ps1'
```

同一命令每次创建一个新会话，由用户选择股票和截止日期。一次只分析一只已登记、身份可验证的沪深股票；不自动批量运行，不恢复旧图，也不复用旧预算。菜单保留 basic、四分析员、中文、研究及风险各一轮。未登记股票、缺少必要日历或协调库归属无法确认时会停止，不能据此声称任意股票已经可用。

开始前屏幕列明本次范围，输入 `START` 才建立新会话。默认密钥只在隐藏提示中输入；不粘贴进命令或聊天。标准 Basic 手动模式隐藏提示一次 Tushare Token 和一次 DeepSeek API Key。财报工作进程从本次会话的一次性匿名标准输入管道接收同一 Tushare Token。单独执行手动财报验收脚本时才使用它自己的隐藏提示。密钥不写入会话结果，不通过参数或复制文件传入子进程。Tushare 仅使用既定 `api.waditu.com` HTTPS 路径，DeepSeek 仅用 `api.deepseek.com`，东方财富只用产品现有精确公开路径；不允许未知重定向。同花顺主营、新浪摘要以及未选的其他服务仍禁用。

若用户希望复用已经存在的项目 `.env`，安装此版本后可显式选择：

```powershell
pwsh -NoProfile -File './scripts/Start-MainlandAnalysis.ps1' -UseProjectEnv
```

此选项只解析入口所在项目根目录的 `.env`，只采用 `TUSHARE_TOKEN` 与 `DEEPSEEK_API_KEY`。不向上搜索，不读取 `.env.enterprise`，不将文件内其他设置载入环境，不执行变量插值；继承的这两个密钥也不会覆盖明确选定的文件值。文件须为普通 UTF-8 文件，最大 64 KiB，不能是符号链接、重解析点或硬链接。支持普通 dotenv 引号、`export` 和注释；缺键、重复键、空值、格式错误或读取中替换文件都会停止，不静默转用其他来源或另存密钥。

本机程序会读取文件内容并仅保留所需两个值于进程内存；这不等于没有凭据或不产生费用。财报 live 子进程只采用其中的 `TUSHARE_TOKEN`，通过固定读取函数获得一次只读权限，凭据不会通过命令参数、环境继承或复制文件传给它；独立 reuse 子进程仍禁止凭据访问。默认不加选项时仍是隐藏手输模式。两种模式都保留每次 `START`、指定目的端、预算、停止规则与秘密脱敏。请保护已有 `.env`，不要将其放入 Git 或分享。

每次财报先按原 TTL 检查缓存。有效缓存直接复用，失效时每表至多一次、总计至多三次请求，无分页或重试。随后由另一个进程零网络复用六项结果（合格视图或已验证缺口）并核对原时间戳，通过后分析仅使用财报缓存。缺失或歧义证据不会被伪造成事实；可选缺口按既有策略降级，必需证据失败停止。

标准 Basic 整次会话最多 60 次物理调用；失败和格式修正均计数。Flash / Pro 显式 `high`，每次输出上限 65536，SDK 网络重试 0。身份、日历和至多 3 次财报请求先从总上限扣除，分析只使用余额。模型输入 Token 和金额没有硬上限，次数/输出上限不能保证费用或成功。

标准 Python 监督进程在启动业务子进程前记录 1200 秒共享期限，后续菜单、确认、凭据输入、财报准备、复用和分析均占用该期限。每个财报工作进程还受原 180 秒上限约束。分析只获得剩余时间，不从零重新计时。外部墙钟计时还可能包含监督进程启动前的交互、PowerShell 启动与退出清理。此设计限单次会话，不是整批股票的时间或费用批准。

新会话位于 `reports/bounded-runs/<随机新ID>/`，包含财报回执、脱敏配置、预算绑定、checkpoint、阶段日志和结果。共享行情及财报缓存仍在原 `data` 目录；严格限额、计数、TTL 和旧时间戳不重置。最终报告仍使用正常 CLI 保存流程；“completed”只表示流程完成，需查看 `terminal_outcome_kind`、准入及最终报告。咨询文字和缺口说明不等于合格决策。

停止后保留目录，不删除标记、增加额度或更换目录续跑同一会话。用户以后主动发起另一个新任务会建立新预算并可能再次收费；自动化代理不因这个入口的存在获得新的调用授权。

可先执行 `-CheckOnly`：只核验已审运行文件和解释器，不导入产品、不查缓存、不读取密钥、不建立运行目录。源码或依赖漂移时停止，应重新审查版本，不能机械刷新绑定。此检查不证明真实网络、缓存时效或模型质量。

## 普通 Full 与日历诊断

先完成本机受审安装并通过源码、解释器与目标目录绑定检查。下面三条命令分别用于预检、真实研究和日历诊断，各自独立执行。

```powershell
./start_tradingagents.ps1 -Full -Ticker 601328.SH -CheckOnly
./start_tradingagents.ps1 -Full -Ticker 601328.SH -Run -UseProjectEnv -SessionMaxCalls 60
./start_tradingagents.ps1 -Full -Ticker 601328.SH -CalendarOnly -Run -UseProjectEnv
```

第一条在本地核查最新选日证据。固定日期的 Full 预检另可指定 `-AnalysisDate`。预检通过只证明相应本地检查通过。第二条会使用项目配置启动真实 Full，自动选日，不能传历史日期。第三条也需要真实调用授权，总预算固定为 1，至多尝试一次交易日历请求，无证券分析、模型或正式研究报告。真实 Full 的验收须核对该次运行的账本、终态和报告。

## 显式股票和日期（仍需 START）

安装这一版本后，可在同一受限入口使用 -Ticker 600919.SH -AnalysisDate 2026-11-01，
并按需同时传入 -UseProjectEnv 和已取得的 -BankSnapshot UUID:SHA256。
这两个参数必须同时提供，不能是空字符串；代码须为六位数字和 .SH、.SS 或 .SZ，
日期须严格为 YYYY-MM-DD 且不晚于上海当日。不会默认换成今天，也不会在参数错误时退回菜单。
-CheckOnly 可同时检查这两个参数的语法及源码绑定，但仍不导入业务、读取凭据或创建会话，
也不代表身份、快照、日历或缓存就绪。

显式选择仅代替菜单，固定 basic、市场/情绪/新闻/基本面四分析员、中文、研究及风险各一轮、
Flash/Pro high 与每次输出上限65536。启动前显示股票、日期和原费用/请求边界，仍须输入原
START；没有 --yes 或跳过确认的选项。显式股票和日期同时使用 -UseProjectEnv 时，
可通过标准输入管道传入 START 及后续报告提示答案。管道中不传递密钥；程序仍只读取
固定项目 .env。不使用 -UseProjectEnv 的隐藏手输模式，以及未指定股票和日期的菜单模式，
仍须终端输入。EOF、空输入或其他确认文字均不能授权新会话。
未提供这两个参数时继续使用原菜单。符号规范化不是权威身份登记；身份、快照有效期、
日历、财报缓存和证据门槛保持原检查。

显式模式不是完全无人值守模式。完成后仍保留 Save report、Save path、Display full report
三个普通文本提示（选择不保存时不询问路径）；代理可通过标准输入回答。
保存路径默认仍在项目 reports 下。EOF或任何停止都不会自动重新付费运行。
.env 仅由程序按原固定路径读取，显式参数不能携带密钥或改变供应商。
显式 Basic 使用同一 1200 秒期限和最多 60 次总调用，其中财报最多 3 次。SDK 零重试，停止后不续跑。

PowerShell 入口用明确的进程对象启动绑定的 Python，逐个传入参数，继承标准输入、输出和
错误流，并等待该进程实际退出后返回 ExitCode。不会把缺失退出码当作成功，也不会靠延时
判断完成。关闭启动器不会授权重跑；若外部控制器断开，须先核对已建立的会话和进程状态。

## 交易所日历与换股预检

新增证券支持必须在原入口验证完整链：显式选择 → 已固定的权威身份（含交易所、币种、上市日期）
→ 交易所日历的完整自然日期覆盖 → 当前缓存兼容性 → Session.precheck。
仅身份单元测试或 CheckOnly 通过，不能据此宣布换股可运行。

CURRENT 个人研究模式可把经过原始响应、内容摘要、发布记录和最新完整范围核验的 SSE
公共日历用于其他已验证 XSHG／CNY／equity 证券。证券代码后缀本身不是权威身份。
新证明类型为 tushare-sse-exchange-calendar-v2；旧 tushare-sse-current-calendar-v1
证明仍只绑定原证券，不重标旧行情或旧缓存。每只证券的价格键、日期、复权方式和事实来源
仍独立。该证明不提供严格历史 PIT 资格。

SZSE 证券不能消费 SSE 日历，继续依赖现有受信的 generic 日历路径；本次不扩展供应商或
开放其他来源。混合存储中受检查来源损坏、最新版本不完整、缺自然日期或身份不匹配都应
明确停止，不能拼接旧版日期、生成交易日或把非交易日当作缺失行情补造。
已命中的 v2 缓存也须重新核对日历来源。明确的来源／生命周期失败须在新价格请求前终止；
完整有效的新日历只使旧证明失效，须独立重建，不能放行旧价格缓存。

更换源码后，不得仅重写缓存兼容清单中的哈希。必须保留旧清单和失败回执，以当前源码
重做限定的合成缓存矩阵、公开缓存入口及受影响适配器验证，再保存新证据及源码指纹。
离线兼容通过只证明所测机制，不证明某个真实缓存正文、日期覆盖、实时接口或账户权限可用。

跨股票回归至少包含：新旧 SSE 证券及别名、SZSE 正例和不能借用 SSE 的负例、未登记／错
交易所身份、上市前日期、过期身份、完整范围边界、缺日／未来观察、非交易日、跨证券缓存
未命中、最新不完整日历及损坏日历不追加价格请求。合成身份、日期和响应必须标记为合成，
不得注册成真实数据。真实所需日历缺口应另行取得受信数据；不得为通过预检放松范围检查。


## 可选财报不完整

统一入口显式启用可选财报缺口准备模式；独立财报脚本默认仍严格要求六个合格视图。
独立脚本的 `--allow-optional-financial-gaps` 必须与精确共享存储绑定一起使用。
仅当前策略声明为可选的财报可以降级。两次工作进程均重新通过真实规范化与评估：
关键字段完整、证券/日期/币种/单位等检查通过，但非关键核心字段覆盖低于90%时，
记录 unavailable，不产生财务制品、canonical fact 或财务投资资格。90%门槛及字段映射不变。
身份冲突、关键字段缺失、错误数字或币种、篡改、缓存失效及必要市场证据不足仍停止。

财报回执保留受限诊断：缺失字段、覆盖率、拒绝类别、原响应哈希、范围及原时间戳。
原始表格值和密钥不会复制进这份诊断。准备成功可能是 passed_degraded；
same_six_outcomes_and_timestamps 表示六项状态一致，旧 same_six_views_and_timestamps
仅在全部合格时为真。父进程只校验受信双进程回执的一致性与来源绑定，
不将自洽JSON当作独立金融认证；分析阶段继续 financial_cache_only，
真实缺口须在报告中披露，不能用其他科目冒充缺失项。

新增财报降级支持的回归必须覆盖原入口的六项比较及独立复用，
不能只验证规范化器，也不能把离线合成流程通过当作真实投资分析已通过。
