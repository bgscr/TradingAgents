# Basic 的可选资金流增强

在原项目主目录使用现有入口，增加 `-Moneyflow`：

```powershell
pwsh -NoProfile -File .\scripts\Start-MainlandAnalysis.ps1 -UseProjectEnv -Ticker 600919.SH -AnalysisDate 2026-11-13 -BankSnapshot '<有效的 UUID:SHA256>' -Moneyflow
```

尖括号内容须换成通过原流程取得且未过期的身份引用；此示例不提供新快照，也不保证该股票的数据和账号权限就绪。可先在同一命令加 `-CheckOnly`，它只核验参数和源码绑定，不读取密钥、查询数据或启动分析。省略 `-Moneyflow` 时不执行此项采集，旧 Basic 默认行为保持不变。所有实际运行仍需现有精确 `START`。

## 精确范围

- 保持 Basic 四分析员、研究和风险各一轮、既有最终评级规则。
- 仅为本次经身份验证的沪深股票查询截止日向前 29 天至截止日，共 30 个自然日。
- 只使用 Tushare 标准 `moneyflow`，固定 `ts_code,trade_date,net_mf_amount`。北交所、基金、指数、热榜、龙虎榜、两融、公告、政策及 `all` 均不由该选项启用。
- 既有 Tushare Token 只在内存中提供给 `https://api.waditu.com/dataapi/moneyflow`；不写命令参数、日志或新增凭据文件。身份与三张财报接口的原准入保持不变。
- 每个会话至多一次资金流 POST，计入原数据＋模型的 60 次预算，失败发送也计数；不增加第 61 次预算。复用已有 Tushare 共享请求协调及 40 次/分钟本地安全上限，无分页、重试、重定向或备用来源。
- 请求全同步，最多读取 64 KiB；每次 I/O 使用最多 30 秒请求期限与会话剩余期限中的较小值。读取逐块检查，预算停止/取消向外传播并关闭连接，不留下后台采集线程。沿用协作式期限：不能保证强行中止操作系统内部的 DNS 阻塞。
- 可复用同一绑定的并发请求结果；保留原获取者的收到时间，并报告本会话新增发送数，不能把复用冒充新的采集。
- 当前 `bounded-moneyflow-v4` / 诊断 v3 保存闭合的阶段、拒绝类别、HTTP 状态及最多四层安全异常链，新增 JSON 资源与列数上限类别。只含固定类型及数值 `errno` / `winerror`，不含实际字段名/值、异常消息、请求正文、Token 或响应正文；提取失败不覆盖首错。关闭错误单列，取消和预算停止仍向外传播。
- 正文达到声明的 `Content-Length` 后可能已释放连接；后续只检查完成状态，不再给已释放的 socket 设置超时。提前 EOF 且声明长度尚未满足会被拒绝，不能仅因已读片段可解析为 JSON 就认定完整。所有仍需读取的路径保留动态限时和容量边界。
- 旧观察 v1 无诊断、v2 对应诊断 v1、v3 对应诊断 v2，按原契约只读展示原响应摘要；新观察 v4 对应诊断 v3 和投影摘要，预算绑定同步更新。不能混用摘要字段、恢复旧尝试/预算或重写旧收据。新分类不能恢复过去未留存的原因。

## 内容、来源和报告

严格核对同股、有效日期、窗口、唯一日期、字段/数值类型及有限值。乱序记录校验后按日期排序；错股、重复、未来或越界日期以及非法数值使整份响应不可用。合法零与缺失不同；字段缺失、无权限、空响应和来源失败均不补零。

行值按 `fields` 名称映射，只投影 `ts_code,trade_date,net_mf_amount`。额外顶层键、data 元数据和额外列在内存丢弃，不执行、不留存、不哈希、不传模型；可选元数据或额外列缺失可正常处理。三项核心列缺失、重复列（包括额外列）、行长与完整列清单不一致、错位值仍不可用，不能猜对应关系。所有 JSON 重复键、NaN/Infinity 仍拒绝；UTF-8、64 KiB、最多16层容器、4096个节点（含键）、64列构成统一解析资源边界，包含被丢弃内容。金额最多六位小数、绝对值不超过 `1e14`，本窗口最多30行；这些是本地保护而非供应商协议保证。

未知元数据不取得已认证语义：`total`、`has_more` 等也不用于证明完整性或启动分页。只展示实际合格行；不承诺全量、连续交易日或无截断。缺少核心数据仅使本项不可用，其他独立分析可以继续；取消、预算耗尽及已有安全停止保持原行为。

`net_mf_amount` 使用供应商给出的净值，单位万元（人民币 10,000 元）。仅对实际返回的合格行求和；不宣称覆盖所有交易日，也不称作“完整20交易日资金流”。它是基于 L2 主动买卖单的统计口径，不能由大小单简单相减替代，不能解释成真实机构身份、持仓变化、资金余额或未来收益预测。资金流也不是媒体新闻或舆情数量。

新观察只保存规范化数字行、身份/窗口、收到时间和 `projected_data_sha256` / `normalized_sha256`。投影摘要绑定固定版本、接口、核心字段、请求绑定与已校验行，不覆盖被丢弃元数据；不再生成 `raw_response_sha256`。旧版本该字段仍表示旧原响应摘要，不能重命名冒充新摘要。两类摘要都不提供原始正文回放或官方真实性认证，也不把辅助观察升级为决策 Source Fact。

同一校验摘要进入情绪分析员的独立“资金流辅助观察”上下文，并进入 `1_analysts/moneyflow.md` 与 `complete_report.md`。成功时可以向已选择的模型提供这些数字及出处；不发送供应商任意文本。未取得合格结果时报告闭合缺失状态。新增观察不进入 SourceFact、策略断言或最终评级规则，也不冒充新闻恢复。

合计表分别列出全采集窗口、情绪回看窗口（截止日减 7 个自然日至截止日，含两端）的查询起止、实际记录起止、合格日记录数和人民币万元合计；记录数不证明完整交易日覆盖。空窗口标为不可用，真实零值才显示零。后续研究、交易及风险节点也通过共同上下文获得重新校验后计算的表，不能把全窗口合计标作短期合计。报告给模型辅助正文增加窗口／合计未逐句核验的明确标注；这不会改写模型原话，也不能保证模型遵循提示。错误的辅助正文不能升级为决定事实，评分规则不变。

所有本次获取的历史记录标记 `retrospective_backfill`。交易日期不证明当时可得；供应商没有提供逐条历史发布/修订版本，此功能不授予严格时点回测资格。当日数据也可能尚未发布完整。

## 官方依据与验证边界

[标准 moneyflow 文档](https://tushare.pro/document/2?doc_id=170)说明最低 2000 积分、单次最多 6000 行和字段单位；本入口限制远小于该单次上限。[积分规则](https://tushare.pro/document/1?doc_id=290)中的积分是准入等级，不是每次扣除的额度；下述真实请求已成功，但不保证未来账号准入，不会自动开通或切换到其他专项接口。[数据更新时间](https://tushare.pro/document/1?doc_id=108)不能代替单条发布时间证据。

旧资金流核验曾完整读取 HTTP 200/业务码0，但因 `envelope_keys` 拒绝，具体额外键及含义仍未知；正文未留存，不追溯恢复。兼容投影经离线合成、假传输、本地协调器、实际图消息与内存报告验证后，2026-11-14 又完成一次独立生产路径核验：600919.SH、2026-10-15 至 11-13，单次 POST，HTTP 200/业务码0，取得22条通过校验的记录，无模型调用。安全收据留在本机 `.scratch/moneyflow-projection-live-20261114-01/`，不纳入代码交付。

上述成功不证明旧失败的具体原因、所有股票持续可用或全交易日覆盖。后续已有正式 Basic 全链路携带资金流、融资余额及 PowerShell 新闻完成并交付报告，但研究／风险辅助正文出现了跨窗口误标合计，首次新闻工具超窗请求也曾误报为上下文缺失。本轮针对性修正仅做离线验证，不追改历史报告，不声称新提示已获模型实跑验证。最终评级规则不变，不据此声称预测准确率提高。详见[主入口与验证状态](bounded-mainland-entry.md)。

## 与融资余额组合

可在同一正式命令同时传入 `-Moneyflow -MarginDate YYYY-MM-DD`，参见 [单日融资余额](bounded-margin-balance.md)。两项各最多一次，共用原60次数据/模型预算及1200秒协作式期限；不启用旧 `all`。资金流字段缺失或融资余额不可用分别披露，不互相补值，也不阻断仍可独立进行的分析；预算/取消及关键证据失败的停止规则保持不变。
