# Current-task handoff template

Use one current handoff for a paused task or a new session. Update it only in an authorized mutable location; keep historical evidence intact and link to it. Do not populate authorization fields from old context. If a contract seals the existing record, place a successor outside that inventory and link back.

```text
Task / terminal or paused status:
Working directory and current branch / commit / tree:
Protected source/evidence identities (references, not execution authority):
Current authorized scope and explicit exclusions:
Attempt/time budget remaining (unknown means verify, not renew):
Retained report and exact evidence paths:
Observed result and what was not reached:
Remaining uncertainty / next unresolved question:
Next proposed observation and how it would distinguish hypotheses (if any):
Exact authority missing before that action, and its governing source:
Fresh-session instruction/configuration sources to load and verify:
Stop condition:
```

A new session must validate any source, packet, session, thread and authorization bindings against its current task. A handoff is continuity information, not permission to resume a stopped experiment or qualification run.
